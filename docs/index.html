05 / FAQ

你大概想问的，都在这

没有销售话术，只有直接的答案。

Q1完全离线的内网环境，能装能用吗？+

安装包自带全部依赖组件（含 Go/Node 运行时、ocserv 源码与系统 deb 离线包），安装时按提示选择完全离线安装即可全程无网操作，不改 apt 源、不发起任何联网请求；授权校验同样无需外网。服务器部署后即可断开外网——零遥测，是本产品的底线而非卖点。

Q215 天试用到期后会怎样？+

到期后服务停止对外提供连接，但数据完整保留。导入正式 License 即刻恢复；即便卸载重装，试用进度与激活状态也会自动延续，不会被"洗掉"。

Q3改了配置，在线用户会掉线吗？+

不会。绝大多数配置保存即生效且不影响在线会话；需要重启服务的场景，面板会先明确提示，把决定权留给你。

Q4域名放行，CDN 换了 IP 怎么办？+

不用管。面板持续解析并自动跟随域名的 IP 变化，规则随动更新。你只需要维护一份域名清单，而不是几百条 IP 规则。

Q5态势大屏的地图要联网加载吗？+

不需要。世界与中国地图数据随安装包内置，IP 归属地同样支持导入离线库（ip2region），纯内网环境下地图、排行、路径与全屏大屏全部照常工作。

Q6支持哪些系统？对服务器有什么要求？+

Debian / Ubuntu，一行命令完成安装，开机自启动。常规云主机规格即可承载；面板自身资源占用极低，不与业务抢资源。

Q7面板本身的安全怎么保证？+

HTTPS 加密访问、bcrypt 密码存储、登录失败阶梯锁定、会话绑定来源 IP、管理员操作全程审计。内部维护接口仅限服务器本机访问，且校验独立令牌。
